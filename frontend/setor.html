Termo de Responsabilidade - Acesso a Dados Pessoais

Como operador de dados no sistema Viagens Labs, você terá acesso a dados pessoais de colaboradores protegidos pela Lei nº 13.709/2018 (LGPD).

⚠️ Dados aos quais você terá acesso:

  • Dados pessoais: Nome, CPF, data de nascimento, celular
  • Dados profissionais: Cargo, filial, centro de custo, gestor
  • Dados de viagem: Origem, destino, datas, serviços, cotações
  • Dados bancários: Contas para reembolso (quando aplicável)

🚨 Suas responsabilidades:

  • Confidencialidade: Não compartilhar dados fora do sistema ou com pessoas não autorizadas
  • Finalidade: Acessar dados somente para gestão de viagens corporativas
  • Segurança: Não exportar, copiar ou armazenar dados fora do sistema oficial
  • Auditoria: Seus acessos são registrados e podem ser auditados a qualquer momento

✓ Uso legítimo dos dados:

  • Pré-aprovar solicitações de viagem
  • Gerenciar cotações com agências
  • Aprovar tickets de acesso para terceiros
  • Gerar relatórios de conformidade e auditoria

Base Legal: O tratamento é necessário para execução de contrato de trabalho (Art. 7º, V, LGPD).

Leia nossa Política de Privacidade Completa para mais detalhes.
