Política de Privacidade

Viagens Labs — Portal Corporativo de Viagens

Última atualização: 23 de junho de 2026

1. Controlador de Dados

Empresa: Magazine Luiza S.A. (Luizalabs)

Endereço: São Paulo, SP — Brasil

E-mail de contato: dpo@luizalabs.com

DPO (Encarregado de Proteção de Dados): Disponível em dpo@luizalabs.com

2. Dados Pessoais Coletados

Ao utilizar o sistema Viagens Labs, coletamos:

  • •
    Dados de Identificação: Nome completo, CPF, data de nascimento, e-mail corporativo
  • •
    Dados Profissionais: Usuário AD, cargo, filial, centro de custo, data de admissão
  • •
    Dados de Viagem: Origem, destino, datas de ida/volta, tipo de serviço (aéreo, hotel, etc.), motivo da viagem
  • •
    Dados de Aprovação: Histórico de aprovações/rejeições, observações de gestores
  • •
    Dados de Sistema: Endereço IP, user-agent, timestamps de acesso

3. Base Legal (Lei nº 13.709/2018 — LGPD)

O processamento de seus dados é baseado em:

  • •
    Art. 7, Inciso V: Execução de contrato de trabalho — os dados são necessários para gerenciar solicitações de viagens corporativas no escopo da relação de emprego.
  • •
    Art. 7, Inciso II: Consentimento explícito — você pode revogar este consentimento a qualquer momento, entendendo o impacto no acesso ao sistema.
  • •
    Art. 7, Inciso I: Consentimento — para fins de auditoria, conformidade e melhorias do sistema.

4. Finalidades do Processamento

Seus dados são processados para:

  • Criar, gerenciar e acompanhar solicitações de viagem corporativa
  • Encaminhar para aprovação de gestores N1 e N2
  • Gerar cotações junto a agências de viagem parceiras
  • Processar reembolsos e pagamentos (integração com sistemas financeiros)
  • Comunicação via e-mail sobre status de solicitações
  • Auditoria interna e conformidade legal (art. 7, inc. II)
  • Melhoria contínua do sistema e análise de métricas

5. Compartilhamento de Dados

Seus dados podem ser compartilhados com:

  • •
    Gestores N1/N2: Para aprovação de suas solicitações
  • •
    Setor de Viagens: Para pré-aprovação e seleção de agências vencedoras
  • •
    Agências de Viagem Parceiras: Cadastradas conforme demanda do setor — para cotação de serviços
  • •
    Sistemas Integrados: Google BigQuery, Gmail Relay, Google Apps Script (para processamento de aprovações)
  • •
    Active Directory (LDAP): Para autenticação corporativa
  • •
    Auditores Internos: Para conformidade e investigações

6. Período de Retenção de Dados

Os dados são mantidos conforme o seguinte cronograma:

Tipo de Dado Período
Solicitações de viagem (ativas) Até conclusão + 3 anos (por auditoria)
Histórico de aprovações 2 anos
Dados pessoais sensíveis (CPF, data nasc.) Encriptados; deletados após solicitação (30 dias)
Logs de auditoria LGPD 2 anos (obrigação legal)
Consentimentos Permanente (prova de aceitar a política)

Nota: Após expiração, os dados são anonimizados ou deletados, exceto quando requerido por lei.

7. Seus Direitos LGPD

Você possui os seguintes direitos:

  • ✓
    Direito de Acesso (Art. 18): Solicitar cópia de todos os seus dados
  • ✓
    Direito de Retificação (Art. 19): Corrigir informações imprecisas
  • ✓
    Direito de Exclusão/Esquecimento (Art. 17): Solicitar exclusão dos dados (com prazo de 30 dias)
  • ✓
    Direito de Portabilidade (Art. 20): Receber dados em formato estruturado para transferência
  • ✓
    Direito de Revogar Consentimento (Art. 8, § 5º): Revogar o consentimento a qualquer momento

Para exercer qualquer destes direitos, envie uma solicitação para:
dpo@luizalabs.com
Prazo para resposta: até 30 dias a contar do recebimento

8. Segurança dos Dados

Implementamos medidas técnicas e administrativas para proteger seus dados:

  • Encriptação HTTPS (TLS 1.3) em trânsito
  • Encriptação em repouso para dados sensíveis (CPF, data de nascimento)
  • Autenticação via Active Directory com MFA quando aplicável
  • Auditoria contínua de acessos a dados sensíveis
  • Isolamento de ambiente (intranet corporativa)
  • Backup regular e plano de recuperação de desastres

9. Processadores de Dados

Utilizamos terceiros para processar seus dados:

  • Google Cloud (BigQuery, Apps Script): Armazenamento e processamento de dados de colaboradores
    Política de Privacidade do Google
  • Microsoft (Active Directory): Autenticação corporativa
    Política de Privacidade da Microsoft
  • Gmail Relay: Envio de e-mails corporativos
    Política de Privacidade do Google

10. Alterações nesta Política

Podemos atualizar esta Política de Privacidade periodicamente. Alterações significativas serão comunicadas via e-mail. Você será solicitado a confirmar a aceitação da versão atualizada ao acessar o sistema.
